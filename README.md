# The One-Line Laugh

Entry for make.fun competition `u-ronigrv-the-one-line-laugh-7ccca46f`:
one funny line, at most 200 characters, judged pairwise by a house judge.

`main.py` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`):

> My smart fridge emailed my doctor about my midnight snacks, then cc'd my mother for backup.

Deterministic, no network, standard library only.
